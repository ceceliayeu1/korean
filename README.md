# OSM Practice Lab

A hands-on restaurant onboarding simulator with eight fictional practice cases. This is an independent training tool, not Tarro software or an internal playbook.

The entire app is in `index.html`. It needs no build, account, backend, API key or external dependencies. Practice progress stays in the learner's browser. No résumé, contact information or saved practice attempts are included.

For GitHub Pages, select this `gh-pages` branch and the `/ (root)` folder as the publishing source in repository Settings > Pages. The `.nojekyll` file publishes the self-contained app directly.
